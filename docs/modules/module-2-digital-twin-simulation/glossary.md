# Module 2 Glossary: Digital Twin Simulation

## Core Concepts

### Digital Twin
A virtual replica of a physical system that enables real-time synchronization and bidirectional data flow between the physical and virtual environments.

### Sensor Simulation
The process of creating virtual sensors that generate realistic data to mimic physical sensors in a digital environment.

### State Synchronization
The process of keeping the virtual system state aligned with the physical system state in real-time.

### Reality Gap
The difference between simulation behavior and real-world behavior, which must be minimized for effective simulation-to-reality transfer.

## Simulation Technologies

### Gazebo
An open-source robotics simulator that provides high-fidelity physics simulation and realistic rendering capabilities.

### Unity Robotics
A set of tools and packages that enable robotics simulation and development within the Unity game engine.

### ROS 2 Bridge
Software component that connects simulation environments to ROS 2 communication systems.

### Physics Engine
Computational system that simulates physical laws and interactions in a virtual environment.

## Sensor Types

### LiDAR (Light Detection and Ranging)
A sensing method that measures distance to objects using laser light, commonly simulated as 2D or 3D point cloud data.

### IMU (Inertial Measurement Unit)
A device that measures acceleration and rotation, simulated to provide data about a robot's motion and orientation.

### Point Cloud
A collection of data points in 3D space, typically generated by 3D sensors like LiDAR or stereo cameras.

### Sensor Fusion
The process of combining data from multiple sensors to improve perception and understanding of the environment.

## Performance Concepts

### LOD (Level of Detail)
Adjusting simulation complexity based on requirements, using different model details depending on factors like distance from camera.

### Fixed Time Step
Using consistent time intervals for physics calculations to ensure stability and predictability in simulation.

### Domain Randomization
Training algorithms with varied simulation parameters to improve their robustness when transferred to real-world applications.

### Progressive Transfer
Gradually introducing real-world conditions into simulation to bridge the gap between virtual and physical environments.

## Validation and Accuracy

### Kinematic Validation
The process of verifying that simulated joint positions and movements match those of the physical robot.

### Dynamic Validation
Validation of forces, torques, and accelerations in the simulation against real-world measurements.

### Simulation Anomaly
Unexpected behavior or error in the simulation environment that may indicate problems with the simulation setup.

### Validation Metrics
Quantitative measures used to assess the accuracy and effectiveness of a simulation environment.

## Simulation Workflows

### Twin Synchronization
The process of maintaining alignment between physical and virtual system states in a digital twin.

### Data Streaming
Continuous transmission of data between physical and virtual systems with minimal latency.

### Twin Accuracy
The degree to which a digital twin matches the behavior of the physical system it represents.

### High-Frequency Data Streaming
Transmission of sensor and control data at high rates (30-1000 Hz) to maintain real-time simulation accuracy.
