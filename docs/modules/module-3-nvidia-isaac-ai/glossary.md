# Module 3 Glossary: NVIDIA Isaac Robotics AI

## Core Concepts

### Isaac Sim
NVIDIA's robotics simulation platform built on the Omniverse platform, providing high-fidelity physics simulation and photorealistic rendering for robotics development.

### Isaac ROS
NVIDIA's collection of hardware-accelerated perception and navigation packages designed for robotics applications, leveraging GPU acceleration for superior performance.

### VSLAM
Visual Simultaneous Localization and Mapping - a technique that uses visual sensors to simultaneously map an environment and localize within it.

### GPU Acceleration
Using graphics processing units to accelerate computational tasks, particularly effective for parallelizable robotics algorithms.

### CUDA
NVIDIA's parallel computing platform and programming model that enables general-purpose processing on GPUs.

## Perception Components

### Isaac ROS Apriltag
GPU-accelerated AprilTag detection package for precise pose estimation using visual fiducial markers.

### Isaac ROS Visual SLAM
Hardware-accelerated visual SLAM implementation for real-time mapping and localization using camera sensors.

### Isaac ROS Stereo DNN
Deep neural network-based stereo vision processing package for enhanced depth estimation.

### Isaac ROS Detection 2D
GPU-accelerated 2D object detection using deep learning models for robotics perception.

### Isaac ROS Depth Segmentation
Package combining depth information with semantic segmentation for 3D object understanding.

## Navigation Components

### Isaac ROS Nav2 GPU Planner
GPU-accelerated path planning implementation of the Nav2 navigation stack.

### Behavior Tree
Hierarchical structure for organizing robot behaviors and decision-making processes in navigation tasks.

### Dynamic Window Approach (DWA)
Local path planning algorithm that considers robot dynamics for obstacle avoidance.

### Costmap
Grid-based representation of navigation costs and obstacles used by navigation algorithms.

### Recovery Behaviors
Actions taken by navigation systems when normal navigation fails or the robot gets stuck.

## Technical Terms

### TensorRT
NVIDIA's SDK for optimizing deep learning inference, used in Isaac ROS for fast neural network execution.

### Bundle Adjustment
Optimization technique for refining 3D structure and camera poses in SLAM systems.

### Loop Closure
Process of recognizing previously visited locations to correct drift in SLAM systems.

### Occupancy Grid
2D grid map representing the probability of space being occupied by obstacles.

### Point Cloud
Collection of 3D points representing the geometry of a scene, typically generated by 3D sensors.

## Algorithms and Methods

### A* Algorithm
Graph traversal algorithm commonly used for global path planning, guaranteeing optimal paths.

### Kalman Filter
Mathematical method for estimating system state from noisy measurements, used in sensor fusion.

### Particle Filter
Sequential Monte Carlo method for state estimation in non-linear, non-Gaussian systems.

### Semantic Segmentation
Process of classifying each pixel in an image into different semantic categories.

### Instance Segmentation
Process of identifying and segmenting individual object instances in an image.

## Performance Concepts

### Real-time Processing
Processing data as it arrives with timing constraints that must be met for proper system operation.

### Multi-threading
Using multiple threads of execution to improve performance and responsiveness of robotics systems.

### Memory Management
Efficient allocation and use of GPU and system memory for robotics algorithms.

### Computational Efficiency
Optimizing algorithms to use minimal computational resources while achieving desired performance.

### Parallel Processing
Executing multiple computations simultaneously, particularly effective on GPU architectures.
