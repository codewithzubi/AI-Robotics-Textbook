# Glossary of Terms

This glossary contains key terms used throughout the Physical AI & Humanoid Robotics textbook. Each term is defined with its meaning in the context of robotics, AI, and simulation.

## A

### Action
In ROS 2, an Action is a communication pattern that allows for long-running tasks with feedback and goal management. Actions extend the basic request/response pattern of services by adding support for long-running transactions, feedback during execution, and the ability to cancel goals.

## C

### Computer Vision
A field of artificial intelligence that trains computers to interpret and understand the visual world. Using digital images from cameras and videos and deep learning models, machines can accurately identify and classify objects and react to what they "see."

## D

### Digital Twin
A digital replica of a physical system, process, or product that uses real-time data to enable analysis, monitoring, and optimization. In robotics, digital twins are used to simulate robot behavior before deployment on real hardware.

## G

### Gazebo
A robotics simulation environment that provides high-fidelity physics simulation and realistic rendering. It is commonly used in robotics research and development to test algorithms and robot designs in a virtual environment before deployment on real robots.

## L

### LLM (Large Language Model)
A type of artificial intelligence model that has been trained on vast amounts of text data to understand and generate human-like text. In robotics, LLMs are used for natural language processing, task planning, and human-robot interaction.

## N

### Node
In ROS (Robot Operating System), a node is a process that performs computation. Nodes are the fundamental building blocks of a ROS system, and they communicate with each other using topics, services, and actions.

## R

### ROS (Robot Operating System)
A flexible framework for writing robot software. It is a collection of tools, libraries, and conventions that aim to simplify the task of creating complex and robust robot behavior across a wide variety of robot platforms.

### ROS 2
The second generation of the Robot Operating System, designed to be suitable for real-world applications. It provides improved security, real-time support, and better architecture for distributed systems.

## S

### Service
In ROS, a Service is a synchronous communication pattern where one node (the client) sends a request to another node (the server) and waits for a response. Services use a request/response model similar to web services.

## T

### Topic
In ROS, a Topic is a named bus over which nodes exchange messages. Topics implement a publishing/subscription communication pattern where publishers send messages to a topic and subscribers receive messages from a topic.

## U

### URDF (Unified Robot Description Format)
An XML format for representing a robot model in ROS. URDF describes the physical and kinematic properties of a robot, including links, joints, and other elements that define the robot's structure.

## V

### VLA (Vision-Language-Action)
A framework that integrates computer vision, natural language processing, and robotic action planning. VLA systems enable robots to understand natural language commands and perform complex tasks based on visual input.

### Vision-Language-Action (VLA) Systems
Advanced robotic systems that combine perception (vision), understanding (language), and execution (action) to perform complex tasks. These systems allow robots to interpret natural language commands and execute corresponding actions in real-world environments.

## W

### Whisper
An automatic speech recognition (ASR) system developed by OpenAI. In robotics, Whisper is used to convert spoken language into text that can be processed by other AI systems for task planning and execution.
